# Task Manager Application

A simple Task Manager Web Application
built using Python and FastAPI.

## Technologies Used
- Python
- FastAPI
- SQLite
- SQLAlchemy
- HTML
- CSS
- Jinja2

## Features
- Add tasks
- View tasks
- Complete tasks
- Delete tasks

## How to Run

1. Clone the repository

2. Install dependencies

pip install -r requirements.txt

3. Run the application

uvicorn main:app --reload

4. Open in browser

http://127.0.0.1:8000
